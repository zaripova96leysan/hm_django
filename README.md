# Django Интернет-магазин

Проект интернет-магазина, разрабатываемый в рамках курса по Django.
В данном домашнем задании реализована начальная настройка проекта:

- Создан Django-проект и приложение `catalog`.
- Настроены маршруты для главной страницы и страницы контактов.
- Подготовлены HTML-шаблоны с использованием Bootstrap.
- Реализованы контроллеры для отображения страниц.

## Запуск проекта

1. Установите зависимости:
pip install -r requirements.txt

2. Выполните миграции:
python manage.py migrate

3. Запустите сервер:
python manage.py runserver

4. Откройте в браузере:
- Главная страница: http://127.0.0.1:8000/
- Контакты: http://127.0.0.1:8000/contacts/

## Технологии

- Python 3.12
- Django 6.1
- Bootstrap 5
